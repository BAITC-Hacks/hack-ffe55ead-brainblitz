# Frontend «Аким на 5 часов»

Ветка `frontend` основана на `main` / `617fc642946d9049f9ae5d8c4644be5ed9161d3e`.
Backend, датасет, формула и API-контракт не изменены. В этой версии main backend отсутствует.

## Просмотр без backend

Из корня репозитория запустите любой статический HTTP-сервер. Например, при установленном Python:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000/static/index.html?demo=1`.
Открытие HTML через `file://` не поддерживается: нужны HTTP и абсолютные пути `/static/*`.
В среде разработки проверен HTTP-просмотр через локальный сервер Node.js и Chromium / Microsoft Edge.

Деморежим включается только явно: `?demo=1` или ссылка «Открыть деморежим».
Ошибка настоящего API никогда не включает mock. JSON в `static/demo/` дословно по структуре и значениям повторяет полные примеры `docs/api-contract.md`; это не отдельный датасет или движок.

1. Нажмите «Загрузить пример»: будет выбран A, стоимость 83.
2. Для A в контракте есть запрос и эталонные числа, но **нет полного SimulationResult и AnalysisResult**. Деморежим честно сообщает об отсутствии ответа; он не синтезирует его из B и не считает Score.
3. Перенесите M7 из Есиля в Нуру. Это B; стоимость остаётся 83.
4. Нажмите «Рассчитать последствия»: появятся полный пример B (Score 55,07, точное значение в JSON 55.0703475) и отдельно подписанный пример AI-текста.
5. Остальные наборы требуют настоящего backend. Каталог позволяет их составлять, но деморежим не выдумывает ответы.

## Подключение к backend

FastAPI должен обслуживать `/` файлом `static/index.html`, `/static/*` — статическими файлами, `/api/config`, `/api/simulate`, `/api/analyze` — по контракту 2.0. Изменения UI и сборка не требуются. Откройте `/` без `demo=1`.

UI строится из GET `/api/config`. Оба POST получают только `{selections: [{measure_id, district_id}]}`. У городской меры район скрывается и передаётся `null`.
При отправке фиксируется отдельный snapshot. `/api/simulate` завершается и показывает числа перед отдельным `/api/analyze` с тем же snapshot. Предварительная проверка заполнения и бюджета не заменяет серверную валидацию конфликтов и правил.

Изменение выбора инвалидирует попытку, скрывает прежний результат с сообщением об устаревании и отменяет запрос. Номер попытки проверяется даже если отмена транспорта не сработала. Ответы также сверяются по selections и версиям; AI — дополнительно по исходному и итоговому Score и evidence_paths. Все динамические строки выводятся через textContent, без HTML-интерпретации.

Загрузка конфигурации ограничена 15 секундами, расчёт — 30, клиентское ожидание AI — 20. Последнее оставляет запас для целевого серверного предела 12 секунд. Скрытых повторных запросов нет. Отказ AI, сеть и `status=unavailable` сохраняют числа. Ошибки HTTP, включая 422, читаются из `detail`; коды и пути используются для маркировки формы.

## Проверки

`tests/frontend.cjs` — браузерные проверки с перехватом API-запросов. Нужен Node.js и доступный Playwright для разработки; сайт не использует его и не загружает библиотеки/CDN.

```sh
node tests/frontend.cjs
```

По умолчанию запускается установленный Microsoft Edge. Для другого Chromium задайте `BROWSER_PATH`. Если Playwright находится вне проекта, задайте `NODE_PATH` на его каталог node_modules. Необязательный `SCREENSHOT_DIR` сохраняет desktop/mobile PNG.

Проверены:

- точное совпадение всех demo JSON с полными примерами контракта;
- выбор A → перенос M7 в Нуру → B, стоимость 83 на обоих шагах; полный результат и AI-пример B;
- отправка A без подмены на B в реальном режиме с тестовым перехватом сети;
- точные POST-тела, одинаковый snapshot, `district_id: null`, скрытие района для городской меры;
- показ чисел до окончания AI; неполный выбор и пропущенный район;
- блокировка стоимости 107 и отправка стоимости ровно 100 на сервер;
- загрузка, ошибка конфигурации и повтор; сетевые ошибки расчёта и AI;
- серверные ошибки 422 из `detail`, отсутствие AI после неуспешного расчёта;
- unavailable, несовпадение selections/версий, безопасный вывод строки с HTML;
- поздний simulate/AI после изменения и возврата выбора, включая транспорт, игнорирующий AbortSignal;
- адаптивная верстка на ширине 390 px без горизонтального переполнения страницы; таблица прокручивается внутри контейнера.

Все API в этих тестах подменены. **Это не успешная backend- или AI-интеграция.**

## Проверить после подключения настоящего backend

- A: стоимость 83, Score 53.8250475 → отображение 53,83; B после переноса M7: стоимость 83, Score 55.0703475 → 55,07.
- Районные показатели и критические пары для A/B, работа синергий и серверных ограничений; frontend их не рассчитывает.
- Живые AI-разборы A/B и семантическая корректность объяснений; fallback отдельно.
- Реальные HTTP 422, server timeout/unavailable, доступность `/static/*` и запуск на втором компьютере.
